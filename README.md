# nextBar

## Descripción del Problema

Un amigo siempre que quiere quedar con un grupo de amigos tarda muchisimo tiempo en poder organizarse con ellos, ya que todos suelen estar bastante ocupados y siempre que proponen un dia hay alguien de su grupo que no puede asistir. Y es un más costoso poder organizar un viaje de varios dias solamente intentando hablarlo por mensaje.

## Funcionamiento previsto

La aplicación web se encarga de generar un calendario para un grupo de usuarios, donde se almacenará los datos que introduzcan los usuarios de ese grupo y pudiendo así filtrar los días donde nadie a introducido ningun dato, es decir, nadie está ocupado esos días. 

## Validación de requisitos 

### ¿Se trata de un problema real del que se tenga conocimiento personal?
 
Si, es un problema que me ha surgido varias veces y aunque existen páginas para intentar resolver esos problemas son muy poco intuitivas.

### ¿Se trata de un problema que para solucionar requiera el despliegue de una aplicación en la nube? 

Si, ya que a un mismo calendario puedan acceder todos los miembros del grupo desde distintas partes y todos tengan acceso a esa información.

### ¿La solución requiere una cierta cantidad de lógica de negocio, en vez de solucionarse sólo almacenando y buscando?

Si, ya que puede filtrarse la información y además mostrar los dias que estan libres para todos.

### ¿El estudiante tiene todos los datos necesarios para poder resolver el problema, o va a requerir que el usuario los introduzca?

Los usuarios deberan introducir los datos necesarios para resolver el problema.
